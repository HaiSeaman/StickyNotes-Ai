# StickyNotes-Ai v1.1.0 架构重构与 BUG 修复报告

## 摘要 / Executive Summary

本报告详细记录了 StickyNotes-Ai 项目在 v1.1.0 版本迭代中的全盘代码审计、重大 BUG 修复、主进程服务化架构解耦、渲染进程 XSS 安全硬化以及 Windows 批处理脚本（BAT）编码兼容性修复的全过程。

---

## 修复维度与问题清单 / Bug & Refactoring List

### 1. 批处理脚本（BAT）双击报错与编码解析 BUG

* **问题现象：** 用户双击 `启动测试软件.bat` 时，终端弹出报错：
  * `'errorlevel' 不是内部或外部命令`
  * `'畨瑁?Node.js锛?' 不是内部或外部命令`
  * `'ron' 不是内部或外部命令`
  * `'ず]' 不是内部或外部命令`
* **根因分析 (Root Cause)：** Windows 系统的 `cmd.exe` 默认在 ANSI（GBK / CP936 编码页）下读取脚本。当 BAT 文件保存为带 BOM 的 UTF-8 编码或包含非 ASCII 中文字符时，命令行解析器会将 UTF-8 多字节字节流错误分割，把字符 `[%errorlevel%]` 割裂成了非法命令 `rlevel` 与 `ron`，将中文文本截断乱码。
* **修复方案：**
  - 使用 PowerShell 原生文件写入引擎生成标准无 BOM 的 **GBK (GB2312/CP936)** 编码文件；
  - 脚本内部配置自动识别逻辑：优先启动已编译的独立 `dist/便签-win32-x64/便签.exe` 程序，未找到时降级启动 Node.js 开发调试模式。

---

### 2. 核心原子落盘并发写冲突 (File I/O Race Condition)

* **问题现象：** 在高频保存便签数据或自动备份时，可能会触发文件内容为空或 JSON 解析异常。
* **根因分析：** `json-io.js` 中的 `saveJSON` 和 `saveJSONSync` 统一使用硬编码的临时文件路径 `filePath + '.tmp'`。当有多个并发落盘任务同时触发时，后续任务会覆盖正在写入的 `.tmp` 文件，破坏了原子性写操作。
* **修复方案：** 引入 `process.pid + Date.now() + crypto.randomBytes(4)` 为每次写入动态生成全局唯一的临时文件名：
  ```javascript
  const uniqueId = process.pid + '-' + Date.now() + '-' + crypto.randomBytes(4).toString('hex');
  const tmp = filePath + '.' + uniqueId + '.tmp';
  ```

### 3. WebDAV 备份列表 XML 容错解析增强

* **问题现象：** 连接部分私有云或第三方 WebDAV 服务端（如 Nextcloud、坚果云）时，列出备份清单返回为空。
* **根因分析：** `main.js` 原有的 PROPFIND XML 正则匹配硬编码了带固定前缀的命名空间，无法解析不带命名空间前缀（如 `<response>`、`<href>`）或非标准前缀（如 `dav:response`）的响应体。
* **修复方案：** 重构 XML 正则解析逻辑，使用忽略命名空间前缀的可变捕获组：
  ```javascript
  const responseRegex = /<([^:>]+:)?response[\s>][\s\S]*?<\/([^:>]+:)?response>/gi;
  const hrefMatch = /<([^:>]+:)?href[^>]*>([^<]+)<\/([^:>]+:)?href>/i.exec(respBlock);
  ```

---

### 4. 主进程服务化解耦重构 (Architecture Refactoring)

* **优化背景：** 主进程 `main.js` 源码膨胀至 5000+ 行，集成了窗口管理、AI 对话/TTS、WebDAV/S3 同步、网络电台等众多无关联逻辑。
* **重构方案：** 创建独立的 `services/` 业务逻辑层，分模块抽离：
  * **`services/aiService.js`：** 封装 AI 流式对话（支持 AbortController 绑定防重入）、模型查询与语音/视频生成；
  * **`services/syncService.js`：** 封装 WebDAV HTTP 上下文构造、跨域请求执行器与 XML 容错解析器。

---

### 5. 渲染进程 XSS 安全硬化 (DOM Security Hardening)

* **优化背景：** 渲染进程 `renderer.js` 包含大量 DOM 节点动态拼接与 HTML 渲染，部分未转义节点存在潜伏的 XSS 渲染风险。
* **修复方案：**
  * 对所有包含动态文本的 DOM 拼接（如闹钟名称、标签名、文件列表等）补全 `escapeHtml` 安全转义；
  * 对富文本与 Markdown 预览区继续保持 `DOMPurify.sanitize` 白名单过滤机制。
