## 🔍 二、 技术实现与架构细节 (Technical Implementation)

### 1. 数据持久化解耦 (Data Layer Decoupling)
- **改动前**: 待办事项绑在便签对象的 `.todos` 数组中，新建/切换便签会导致待办被清空重置。
- **改动后**: 通过 `userData/todos.json` 与 `userData/todos_archived.json` 独立存储，在 `renderer.js` 中维护常驻 `todos` 内存变量，全局独立读写。

### 2. Popout 小窗口拖拽区域（-webkit-app-region）修复
- **根因**: `.titlebar` 设置了 `drag`，在 Electron 运行环境中将鼠标点击直接吞掉，使得子元素按钮无法接收点击。
- **解决方案**: 为 `.titlebar-actions` 和 `.tb-btn` 显式设置 `-webkit-app-region: no-drag`，恢复了交互事件。

### 3. 高频写入防抖合并 (Debounced I/O)
- 增加 400ms 防抖 `saveTodosToDiskDebounced`，解决用户快速打字高频触发现盘写操作的性能瓶颈；在软件退出 `beforeunload` 时提供同步 `flush` 机制保证零丢包。

## 📦 四、 构建与打包指南 (Packaging Guide)

要打包生成独立 Win32/64 可执行程序 `.exe`，请按以下步骤操作：

```bash
# 1. 安装构建依赖
npm install electron-builder --save-dev

# 2. 执行打包命令
npm run dist
```

打包产物将自动输出在项目的 `dist/` 文件夹下。
