## ✨ v2.9 核心亮点

### 🛡️ 关键 Bug 修复（5 项 P0）

| 问题 | 修复效果 |
|---|---|
| 🔴 首次启动无法使用便签 | 新建用户输入内容无法保存、"+"新建无反应的严重问题已修复 |
| 🔴 软件锁 PIN 永久锁死 | 设置 PIN 后无法修改 / 清除；现设置面板新增「软件锁 PIN」入口，支持修改与清除 |

### ⚡ 性能优化
- 📷 **聊天大图不再卡界面**：图片异步读取，20MB 级图片不再阻塞主进程
- 🎵 **音乐扫描大幅提速**：2000 个文件并发 realpath，扫描文件夹近乎实时
- 💾 **备份更安全**：新增 200MB 内存上限保护；自动同步自动排除大体积聊天图片目录
- 🖥️ **界面更流畅**：会话列表改事件委托渲染，监听器与重绘开销显著下降

### 🧹 代码瘦身（约 950 行）
- 5 个搜索引擎 Provider 抽取公共骨架，消除约 70% 复制粘贴代码
- FM 电台加载、音乐曲目构建等重复逻辑统一收敛
- 清理 6 个从未被调用的死 IPC 通道、整份死类型契约、2 个冗余 npm 依赖、4 个残留文件

### ✅ 测试强化
- 单元测试 **64 → 80 个**，新增搜索引擎工具与本地文件协议 Range 读取回归测试
- 全量测试通过 + 主进程 / 渲染层双工程编译通过
